# Davey Hughes

<a href="https://github.com/Davey-Hughes/glyphedron"><img align="right" width="240" alt="A truncated icosahedron spinning in a terminal, drawn in text characters by glyphedron" src="https://daveyhughes.com/readme/glyphedron/readme.webp"></a>

I mostly work on personal projects, emulators, Linux stuff, and the tools I use every day. There's more detail on all of this at **[daveyhughes.com/os](https://daveyhughes.com/os)**.

### Projects

- **[portfolio](https://github.com/Davey-Hughes/portfolio)**: my self-hosted photography site, [daveyhughes.com](https://daveyhughes.com), with a mosaic gallery layout that fits each photo to a cell by its shape
- **[redextape](https://github.com/Davey-Hughes/redextape)** ([redextape.com](https://redextape.com)): you write a program in a small language and it runs as both a Turing machine and a lambda calculus term, side by side in the browser
- **[plaintextesports](https://github.com/Davey-Hughes/plaintextesports)** ([plaintextesports.com](https://plaintextesports.com)): a fast, plain-text schedule of the big CS2 and League matches, plus NFL, NBA, NHL and MLB games, inspired by plaintextsports.com
- **[taiyaku](https://github.com/Davey-Hughes/taiyaku)**: read manga, comics, and ebooks in more than one language at once, with the editions lined up page by page
- **[subcheck](https://github.com/Davey-Hughes/subcheck)**: has an LLM proofread the subtitles in MKV files, then lets you go through the fixes one by one
- **[glyphedron](https://github.com/Davey-Hughes/glyphedron)**: spinning 3D shapes drawn with text characters in the terminal, just C and ncurses
- **[advent-of-code](https://github.com/Davey-Hughes/advent-of-code)**: my Advent of Code solutions in Rust, for 2019 and 2023 through 2025
- **[.vim](https://github.com/Davey-Hughes/.vim)**: my Neovim config, with plugins managed by lazy.nvim
- **[daveyutils](https://github.com/Davey-Hughes/daveyutils)**: random command-line utilities I use for ripping discs, converting media, etc.

### Contributions

- **[RetroArch](https://github.com/libretro/RetroArch)**: VR headset support with OpenXR, a way for cores to show more than one screen, and second screen output on Android
- **[libretro cores](https://github.com/libretro)**: the Virtual Boy in stereo, the Wii U's TV and GamePad as two screens, and Doom 3 in VR
- **[Linux kernel (amdgpu)](https://lore.kernel.org/all/20261028-freesync-plane-reset-time-v2-0-545a0f9b17df@gmail.com/)**: a fix for fullscreen games getting stuck around 51 fps on FreeSync monitors with HDR on in KWin
- **[Mesa](https://gitlab.freedesktop.org/mesa/mesa)**: lets Vulkan apps that draw straight to the display run without vsync
- **[KIO](https://invent.kde.org/frameworks/kio)**: a fix for folders that wouldn't delete from NFS shares in Dolphin
- **[Azahar](https://github.com/azahar-emu/azahar)**: some rendering fixes for the 3DS emulator
- **[FinalBurn Neo](https://github.com/finalburnneo/FBNeo)**: support for zstd-compressed files in ROM zips, and a fix for a couple of NES mappers going past their work RAM
- **[tmux-powerkit](https://github.com/fabioluciano/tmux-powerkit)**: a window icon per command, and a fix for where window boundaries get drawn
- **[genTB](https://github.com/farhat-lab/gentb-site)**: pipeline commands and cluster job pages for the Farhat Lab's tuberculosis genomics site
